# Excel Portfolio Project : Sales Perfomance Analysis
## Project Overview
This project analyzes a dataset of sales performance data using Microsoft Excel.
## Business Objective
The objective is to identify which product categories, regions, and sales channels contribute the most to clean revenue and profit, while also documenting data quality issues that should be reviewed before making dashboard-based decisions.
## Dataset
The dataset contains order-level sales records with fields such as order date, customer name, region, channel, order status, product, quantity, revenue, cost, profit, and sales representative
## Tools Used
- Microsoft Excel
- Excel formulas
- Power Query
- PivotTable
- Excel Dashboard
## Analysis Process
- Reviewed raw sales order data
- Standardized text fields such as region, channel, status, and category
- Converted date and numeric fileds into consistent format
- Reviewed duplicate orders, missing values, and unusual status records
- Built summary analysis for revenue, profit, order count, average order value, and margin
- Created a dashboard preview and business insights
